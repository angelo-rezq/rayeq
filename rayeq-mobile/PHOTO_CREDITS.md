# Rayeq demo imagery

Checked 22 November 2026. These images illustrate an owner-requested UI demo. Depicted people are not represented as Rayeq employees or endorsers. English names, sample reviews, ratings and years are fictional fixtures in `lib/demo_data.dart`. The UI labels these as demo content and only shows the sample directory when the API catalog sets `isDemo=true`.

## Created illustrations

- `service-hair.webp`, `service-beard.webp`, `service-ritual.webp`: cropped panels from an original generated editorial grooming still life. Not a photograph of Rayeq staff, premises or actual equipment.
- `grooming.webp`: earlier original generated grooming illustration.
- Service/detail screens label fallback service imagery as illustrative.
